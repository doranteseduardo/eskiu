Migrating to Eskiu 0.11

Eskiu 0.11 removes the stdlib names that 0.9.2 and 0.10.1 renamed. Until 0.10.1 they still compiled as thin wrappers over the new names; now a program that uses one gets an "undefined function" error. Each table below maps an old name to the one that replaces it, with the same arguments unless noted. A function whose first parameter is the module's struct can also be called with dot syntax: rng.next() is Rng_next(&rng).

From 0.12 on, a rename follows stability.md: the old name stays for one minor release, marked deprecated("use NEW"), so each use prints a warning that names the replacement.

Without a wrapper (0.10.1)

Old name New name Note
bsearch<T> sort_search<T> bsearch clashed with the C library function.
select2_hdr, join2_hdr, spawn_hdr select2, join2, spawn The type-erased cores are internal (_select2_hdr, ...).
Undocumented helpers (re_*, JParser_*, mp_*, http_lc, h2_* internals, ...) none Internal now, with a leading _. Use the documented API of the module.

Other changes that need an edit

  • 0.10.1: <mem> declares strcmp, strncmp, strchr and strstr (strchr and strstr return *char). A program that imports <mem>, directly or through another module, and declares one of them with different types gets a "conflicting declaration" error: remove its own extern.
  • 0.9.2: the language follows C in places where it did not before. A global's initializer must be a constant (a call or a read of a non-const global is an error); integer promotions and the usual arithmetic conversions apply (a comparison of a signed and an unsigned value converts as in C); octal literals start with 0 (010 is 8, and a digit 8 or 9 there is an error); a struct literal checks each field and zero-fills the rest; a duplicate declaration in one scope is an error. The 0.9.2 section of CHANGELOG.md lists each rule.
  • 0.9.2: -lm, -lc++ and -lpthread are no longer needed on the command line: a module names its libraries with #pragma link, and the driver adds the C++ and thread runtimes when the program uses them.
