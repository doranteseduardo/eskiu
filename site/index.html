Why Eskiu

One language instead of four.

Compute-intensive services lean on C for speed, Go for concurrency, C++ for libraries, and something else for glue. That's four toolchains to keep in sync, and Eskiu does the whole job in one.

Native speed

Compiled to machine code by LLVM. With no garbage collector and no runtime, throughput stays predictable under load.

Explicit memory

alloc<T>(N) and free(ptr) from <mem>. Allocation is visible in the code, never hidden.

Direct C interop

extern any C library (OpenSSL, POSIX, sockets) with no binding layer.

Metal to backend

Boots a kernel in QEMU without libc, and runs a TCP/HTTP server, with the same toolchain at both ends.

Examples

It reads like C.

Each tab below is a complete program that compiles and runs.

hello.esk
extern int printf(string fmt, ...);
import <list>;

int main() {
    let nums: List<int>;
    List_init(&nums, 4);
    for (int i = 0; i < 5; i += 1) { List_push(&nums, i * i); }

    for (n in nums) { printf("%d\n", n); }   // 0 1 4 9 16
    return 0;
}
server.esk
import <net>;
import <mem>;

// A web server using sockets from the stdlib.
int main() {
    int fd = net_tcp_listen(8080);
    *uint8 req = alloc<uint8>(4096);
    while (1) {
        int c = net_accept(fd);
        net_recv(c, (*void)req, 4096);
        net_send_str(c, "HTTP/1.1 200 OK\r\n\r\nHello from Eskiu.\n");
        net_close(c);
    }
    return 0;
}
shapes.esk
extern int printf(string fmt, ...);

interface Shape { float area(); }

struct Circle {
    float radius;
    float area() { return self.radius * self.radius * 3.14159; }
}

// Structural: a struct satisfies Shape just by having area().
void render(Shape s) { printf("area = %f\n", s.area()); }

int main() {
    let c: Circle = Circle { radius: 5.0 };
    render(&c);              // area = 78.54
    return 0;
}
result.esk
extern int printf(string fmt, ...);
import <result>;

Result<int, string> divide(int a, int b) {
    if (b == 0) { return Err<int, string>("divide by zero"); }
    return Ok<int, string>(a / b);
}

// `?` returns the Err early, or unwraps the value.
Result<int, string> ratio(int a, int b, int c) {
    let x: int = divide(a, b)?;
    return Ok<int, string>(x + c);
}

int main() {
    let r: Result<int, string> = ratio(10, 2, 1);
    if (r.ok == 1) { printf("result = %d\n", r.value); }  // result = 6
    return 0;
}
Proof

Faster than the reference C, and it boots on bare metal.

A real cryptographic pipeline (AES-256-CBC + RSA-8192 decryption, image processing, and structured output) running entirely in Eskiu via extern C interop.

A kernel, in Eskiu, on bare metal.

An ARM64 kernel written in Eskiu boots in QEMU on the PL011 UART, with no libc and no C runtime. Freestanding mode, inline assembly, and volatile MMIO are part of the language.

Get started

Compile and run in one step.

Build from source in under a minute. LLVM and a C toolchain are the only dependencies, and eskiuc links the executable for you.

$ git clone https://github.com/doranteseduardo/eskiu
$ cmake -S eskiu -B build && cmake --build build   # build eskiuc
$ eskiuc hello.esk -o hello && ./hello             # compile, link & run
