v0.3.0

A systems language for
compute-intensive work.

Eskiu compiles to native binaries through LLVM, with manual memory and the C ABI. It brings generics, sum types, interfaces, and async/await to that level, so one language covers work that teams usually split across C, Go, and C++.

Get started → View on GitHub
bash 
$ git clone https://github.com/doranteseduardo/eskiu
Cloning into 'eskiu'...

$ cmake -S eskiu -B build && cmake --build build
[100%] Built target eskiuc

$ cat hello.esk
extern int printf(string fmt, ...);
int main() {
    printf("Hello from Eskiu.\n");
    return 0;
}

$ eskiuc run hello.esk
Hello from Eskiu.
Examples

Read an example, run it.

Load one of the example programs and run it in place, or write your own. The server compiles it with LLVM and runs it through the same eskiuc run you would use locally.

Sandboxed: no network, time- and memory-limited, output capped. For the full toolchain, install eskiuc locally.

Get started

Download the compiler.

Grab a prebuilt binary, untar it into /usr/local, and run eskiuc --version. The stdlib is bundled, so imports work right away.
